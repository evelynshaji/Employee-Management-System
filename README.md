
# Employee Management System

A menu-driven Employee Management System built using Python OOP, JSON, and file handling.

## Features
- Add employee details
- View all employees
- Search employees by ID
- Update employee salary
- Delete employee records
- Store employee data in a JSON file

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Run:

   python main.py

## Concepts Practiced
- Classes and Objects
- Constructors
- Methods
- Lists and Dictionaries
- JSON Serialization
- File Handling
- CRUD Operations
